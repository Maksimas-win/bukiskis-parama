# 1,2 % GPM — информационный гид

[![Build and publish](https://github.com/Maksimas-win/bukiskis-parama/actions/workflows/publish-site.yml/badge.svg)](https://github.com/Maksimas-win/bukiskis-parama/actions/workflows/publish-site.yml)

**[Открыть сайт](https://hram.lt/)** · [SEO и Search Console](SEO.md) · [Источники](SOURCES.md) · [История изменений](CHANGELOG.md)

Версия **0.5.9**. Статический информационный сайт на русском, литовском, английском, польском, немецком и украинском. Инструкция FR0512, калькулятор, видео VMI с предварительным согласием, FAQ и локальный помощник. Отдельный добровольный раздел поддержки прихода расположен после справочной части.

Сайт работает без серверной базы данных и внешних runtime-пакетов. Калькулятор и поиск по материалам работают локально в браузере. Кнопка «Спросить ИИ» после отдельного согласия отправляет вопрос, язык и до трёх последних пар сообщений через Cloudflare Worker (`workers/ai-router`) в OpenAI; данные калькулятора не передаются, диалог на сервере не хранится. Подробности — на странице «Конфиденциальность». Тексты доступны без JavaScript; 3D-вступление имеет статический вариант и учитывает reduced motion.

## Разработка

Нужен Node.js 22 или новее. Установка npm-пакетов для сборки не требуется.

```sh
npm run build
npm test
npm run preview
```

Предпросмотр: `http://127.0.0.1:4173/`. После изменения исходников пересоберите `docs` и включите результат в тот же коммит. CI проверяет воспроизводимость сборки.

## Структура

```text
src/
  site.config.json       адрес сайта, периоды и сведения прихода
  locales/               переводы и подписи интерфейса
  app.js, math.js         логика страницы и расчёты
  styles.css             стили основной страницы
  assets/                исходники 3D, помощника и изображений
scripts/                 сборка, предпросмотр и проверки
tests/                   автоматические регрессионные проверки
docs/                    готовый сайт
  index.html, 404.html
  ru/, lt/, en/, pl/, de/, uk/
  assets/css/            стили
  assets/js/             логика и языковые данные
  assets/img/            локальные изображения и favicon
  assets/fonts/          место для локальных шрифтов; сейчас системные
  sitemap.xml, robots.txt
```

Старые адреса в `docs/assets/` сохраняются как совместимые копии для ранее открытых и кэшированных страниц. Новые страницы используют только каталоги css/js/img.

При входе сразу доступен гид GPM. Обращение прихода находится обычным текстом в добровольном разделе помощи и переведено на все шесть языков. Две фотографии предоставлены владельцем 9 октября 2026 года: общий вид используется в карточке с ручным увеличением, второй ракурс — рядом с обращением. Они не относятся к визуализациям проектов и не показываются в информационной части.

Кнопка «Чтение» в шапке включает умеренно увеличенный текст, высокий контраст и отключает движение. Предпочтение хранится только в localStorage (`gpm:reading-mode:v1`) и действует при смене языка и перезагрузке. При запрете хранилища кнопка продолжает работать на текущей странице. Обычный текст и мелкие подписи также стали крупнее; на телефонах убран дополнительный участок прокрутки 3D-вступления.

Калькулятор показывает математические 1,2 % от примера GPM отдельно от общего итога с порогом VMI: назначение меньше 3 € от одного участника одному получателю за налоговый год не включается в итог. Окончательная сумма остаётся решением VMI.

Уведомление о cookies сохраняет подтверждение в localStorage (`bukiskis-parama:privacy-notice:v1`). Оно не включает YouTube и не добавляет трекеры. Повторное открытие — кнопка Cookies внизу сайта.

`docs` генерируется заново. Не редактируйте его файлы вручную. Данные Google для подтверждения сайта хранятся в конфигурации и восстанавливаются при сборке.

## Публикация

В **Settings → Pages → Source** выбран **GitHub Actions**. Единственный рабочий процесс публикации — `.github/workflows/publish-site.yml`:

1. Собрать шесть языков, выполнить регрессионные проверки и сравнить результат с `docs` в коммите.
2. Проверить Chromium на компьютере и мобильных размерах, работу помощника, reduced motion и варианты без JavaScript/WebGL.
3. Опубликовать проверенный артефакт из `main` в GitHub Pages и готовые файлы в ветку `hostinger`, которую автоматически разворачивает Hostinger на **https://hram.lt/**.
4. Сравнить опубликованные файлы с проверенной сборкой; сохранить отчёт в Actions.

Pull request проходит проверки без публикации. Только задача `publish-hostinger` имеет `contents: write`: она обновляет отдельную ветку готовых файлов после успешных проверок. Пароли FTP и ключи SSH не нужны. Исторические проверки отдельных функций остаются в Git как история, но отключены от автоматических запусков.

При ошибке build сайт не обновляется. При ошибке verify откройте артефакт `live-verification-hostinger` или `live-verification-github-pages` — он содержит пути несовпавших файлов. Локальный запуск проверки основного сайта: `npm run check:live`.

### Откат

Сделайте обычный `git revert` проблемного коммита, включающий исходники и сгенерированные файлы. Затем отправьте его в `main`: предыдущая рабочая версия снова пройдёт проверки и публикацию. Не используйте force push и не возвращайте источник Pages на `/docs`.

### Hostinger

На hram.lt подключите репозиторий `Maksimas-win/bukiskis-parama`, ветку `hostinger`, каталог `public_html` и автоматическое развёртывание. Ветка содержит только **готовое содержимое `docs`**, включая настройки HTTPS и страницы 404. Исходники остаются в `main`. Подробности и порядок отката — в [hosting/README.txt](hosting/README.txt). Дополнительный сервер приложений не требуется; OpenAI работает через существующий Cloudflare Worker.

## Проверки и ограничения

`npm test` проверяет расчёты, переводы, HTML-ссылки, размещение ресурсов, SEO, Google verification, логику помощника и сохранение предупреждений. Браузерные проверки запускаются в CI; screenshots и результаты доступны в артефакте `browser-checks`. Они не заменяют тесты на физических устройствах или во всех браузерах.

Индексация включена. Запрос в Google и зелёная сборка не означают, что страница уже есть в поисковой выдаче; статус проверяется в Search Console.

`recipientVerified` и `gpmBankAccountVerified` остаются `false`. Контрольная сумма IBAN не подтверждает владельца счёта или статус получателя в EDS. Не меняйте эти флаги без фактического подтверждения. Дата проверки источников не обновляется автоматически при техническом выпуске.

Информационная часть сохраняет нейтральное оформление. Концепции проектов подписаны; данные о собранных суммах и выполненных работах не выдумываются. Подробные ограничения — в [AGENTS.md](AGENTS.md).
