# 1,2 % GPM — информационный гид

Подготовленная версия сайта: **0.2.0**.

Нейтральный информационный дизайн без крестов и религиозного оформления. Языки: русский, литовский, английский, польский, немецкий и украинский. Инструкция FR0512, калькулятор, видео VMI, вопросы и ответы, официальные источники и отдельный добровольный раздел помощи приходу.

Страница предназначена для подготовки к кампании 2027 года за доходы 2026 года. Она не является сайтом VMI. Подтверждение конкретного получателя в EDS и счёта в Mano VMI остаётся отдельной организационной проверкой.

## Размещение

Идёт первоначальная загрузка подготовленного проекта. Наличие репозитория пока не означает, что сайт уже доступен через GitHub Pages.
