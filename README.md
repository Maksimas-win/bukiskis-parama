# 1,2 % GPM — информационный гид

**Версия 0.2.0 · 29 сентября 2026 года.** Отдельный статический проект для GitHub Pages. Языки: русский, литовский, английский, польский, немецкий и украинский.

Это информационный сайт, а не церковный лендинг. Кресты, религиозные логотипы, силуэты и фотографии храма удалены из интерфейса и favicon. Помощь храму сохранена отдельным добровольным разделом после всей справочной части.

**Статус:** исходники и готовая папка `docs` собраны локально. Новый репозиторий и публикация на GitHub в рамках этой сборки не создавались. Существующие сайты прихода не изменялись.

## Быстрый просмотр

Распакуйте архив и откройте `docs/index.html`. Для полноценной проверки ссылок, политики безопасности и видеоблока предпочтителен локальный сервер:

```sh
npm run preview
```

Требуется Node.js 22 или новее. Пакеты устанавливать не нужно. Откройте локальный адрес из терминала. Сервер доступен только на вашем компьютере.

## Что изменилось

Новый первый экран — «1,2 % GPM. Понятно и по шагам». Вместо фотографии и церковного знака используются типографический знак процента, светлая сине-графитовая палитра и раскрывающиеся пояснения. Основные кнопки ведут к инструкции и видео, а не к пожертвованию.

Порядок разделов: введение → отличие GPM от прямого пожертвования → пять шагов FR0512 → калькулятор → видео → вопросы → официальные источники → отдельная помощь храму → реквизиты и контакты.

В инструкции выбор получателя описан нейтрально. Реквизиты прихода приведены как явно обозначенный пример, а не как единственный доступный выбор.

Сохранены все шесть языков, местные расчёты, видео после нажатия, пояснения к изображениям проектов, копирование реквизитов, печать, работа с клавиатурой и чтение без JavaScript. Виды концепций не выданы за выполненные работы. Подтверждение данных получателя и счёта не имитируется.

## Размещение на GitHub Pages

Предлагаемое имя отдельного репозитория: `bukiskis-parama`.

Description:

> Multilingual information guide to Lithuania’s 1.2% GPM: instructions, explanations, calculator, video and sources. Separate optional parish-support section. RU · LT · EN · PL · DE · UK.

1. Создайте новый репозиторий и загрузите **содержимое** папки `bukiskis-parama`, а не ZIP. Папка `docs` должна находиться прямо в корне репозитория.
2. Откройте **Settings → Pages → Deploy from a branch → main → /docs → Save**.
3. Дождитесь окончания развёртывания и откройте адрес, показанный GitHub Pages.

При замене прежней версии 0.1.0 **удалите прежнюю папку `docs`, затем загрузите новую целиком**. Простое добавление новых файлов через веб-интерфейс может оставить старые изображения в репозитории. Пересборка командой `npm run build` очищает `docs` автоматически. Исходную папку `src` также замените полностью, чтобы не сохранить прежнее изображение храма.

Готовый HTML включён в архив; запускать Node.js на GitHub для публикации не требуется. Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Редактирование

- `src/locales/*.json` — тексты шести языков.
- `src/site.config.json` — периоды, реквизиты, ссылки и статус проверки.
- `src/styles.css` — стили.
- `src/app.js` — интерактивные функции.
- `src/media.json` — сведения об изображениях.
- `scripts/build.mjs` — сборка HTML и копирование ресурсов в `docs`.

После изменения исходников:

```sh
npm run build
npm test
```

Выпуск 0.2.0 изменяет дизайн и подачу, а не вводит новое толкование законодательства. Дата содержательной проверки сохранена из предыдущей версии, автоматически не обновляется. Источники и ограничения описаны в `SOURCES.md`.

## Проверка до массовой публикации

В конфигурации намеренно сохранены `recipientVerified: false`, `gpmBankAccountVerified: false`, `indexingEnabled: false` и пустой `publicBaseUrl`.

Право религиозных общин на поддержку в целом не заменяет проверку конкретного прихода в EDS. Не переключайте флаги до фактического подтверждения получателя и назначения счёта в Mano VMI. Границы кампании и пять налоговых периодов сохранены из исходной версии.

После фактической публикации внесите адрес сайта в `publicBaseUrl`, с завершающим `/`, и пересоберите. Тогда добавятся абсолютные canonical/hreflang и sitemap. Индексация включается только после проверки; `noindex` не делает опубликованную страницу приватной.

Остаются вопросы старых многолетних FR0512, учёта и отчётности прихода, а также актуальности интерфейса EDS перед кампанией. Сайт не утверждает, что они решены.

## Изображения и видео

Первая карточка в разделе помощи использует нейтральную схему помещения. Концепция кухни сохранена локально в исходном разрешении 480 × 270; желательно заменить её качественным оригиналом. Изображение беседки пока может загружаться с GitHub, с подписанной резервной SVG-иллюстрацией при ошибке. Фотография и иллюстрация храма не загружаются ни на первом экране, ни в карточках.

`npm run assets` — необязательная загрузка отсутствующего изображения беседки в проект при наличии сети. После неё нужно выполнить сборку. Не заменяйте понятные схемы несуществующими фотографиями или неутверждёнными визуализациями.

YouTube включается отдельно посетителем. Проверка создания и удаления плеера не равна проверке реального воспроизведения: его нужно проверить на опубликованном домене. На сайте не собираются налоговые сведения, данные карт и пароли. Калькулятор не передаёт значения на сервер.

## Проверка качества

Результаты и границы проверки: `qa/REPORT.md`. Скриншоты: папка `preview`. Они относятся к версии 0.2.0. Изображение беседки на локальных снимках может быть резервной иллюстрацией; это не фотография готового объекта.

Дополнительные браузерные тесты используют Python, Playwright и BeautifulSoup. Они не нужны для работы и публикации самого сайта.

```sh
python tests/browser_smoke.py
python tests/browser_http.py
```

Перед широкой рассылкой проверьте опубликованный адрес, реальное воспроизведение видео, внешнее изображение, ссылки, поведение на физических мобильных устройствах и переводы. Публикация, банковское подтверждение и живое видео не подменяются тестом локальных файлов.
