### Однократное включение сайта

Откройте [Settings → Pages](https://github.com/Maksimas-win/bukiskis-parama/settings/pages) и установите:

- Source: **Deploy from a branch**.
- Branch: **main**, папка **/docs**.
- Нажмите **Save** и дождитесь успешного развёртывания.

Папка `docs` уже содержит готовый сайт. Загружать архив, запускать `START.cmd` или устанавливать программы на компьютер не требуется.

Ожидаемый адрес после активации: **https://maksimas-win.github.io/bukiskis-parama/**. Подтверждением публикации служит успешное развёртывание в Pages и открывающаяся страница, а не только зелёный результат сборки.

## Содержание

Первый экран: «1,2 % GPM. Понятно и по шагам». Светлая сине-графитовая палитра, знак процента и раскрывающиеся пояснения. Основные действия ведут к инструкции и видео.

Порядок разделов: введение → отличие GPM от прямого пожертвования → пять шагов FR0512 → калькулятор → видео → вопросы → официальные источники → отдельная помощь храму → реквизиты.

Выбор получателя описан нейтрально. Приходские реквизиты приведены как подписанный пример, а не как единственный доступный выбор. Учебные схемы не выдаются за настоящие экраны EDS. Концепции проектов не выдаются за выполненные работы.

На всех языках сохранены пояснения, копирование реквизитов, печать, управление с клавиатуры, статический текст без JavaScript и страницы конфиденциальности. Калькулятор работает в браузере; видео загружается только после отдельного нажатия посетителя.

## Структура и редактирование

- `docs/` — готовые страницы и ресурсы для GitHub Pages.
- `src/locales/*.json` — тексты шести языков.
- `src/site.config.json` — периоды, реквизиты, ссылки и флаги фактической проверки.
- `src/styles.css`, `src/app.js` — оформление и интерактивность.
- `src/media.json`, `src/assets/images/` — изображения и сведения о них.
- `scripts/build.mjs` — сборка; очищает `docs` перед созданием новой версии.
- `tests/` — автоматические проверки.
- `SOURCES.md`, `qa/REPORT.md` — источники и границы предыдущих проверок.
- `.github/workflows/publish-site.yml` — автоматическая сборка, тесты и подготовка публикации.
- `.release/v0.2.0/` — контрольная копия первоначально переданных исходников; проверяется по SHA-256. При наличии `package.json` сценарий не распаковывает её повторно и не откатывает последующие изменения.

Для локальной разработки нужен Node.js 22 или новее. Внешние пакеты для сборки не требуются:

```sh
npm run build
npm test
npm run preview
```

После изменения исходников в `main` сценарий GitHub Actions пересобирает `docs`, запускает тесты и сохраняет готовые страницы обычным коммитом, без принудительного изменения истории. Когда Pages включён, предусмотрен отдельный шаг развёртывания. Результат каждого запуска необходимо проверять во вкладке Actions.

При сборке на GitHub адрес задаётся переменной `SITE_URL=https://maksimas-win.github.io/bukiskis-parama/`. Для локальной сборки с абсолютными canonical/hreflang можно задать такую же переменную окружения или заполнить `publicBaseUrl` в конфигурации. При смене домена адрес нужно обновить.

## Что не следует считать подтверждённым

В конфигурации намеренно оставлены `recipientVerified: false`, `gpmBankAccountVerified: false` и `indexingEnabled: false`. Публикация кода не подтверждает доступность конкретного получателя в EDS и назначение банковского счёта в Mano VMI. Флаги меняются только после фактической проверки.

Дата содержательной проверки автоматически не обновляется. Выпуск 0.2.0 меняет дизайн и подачу, а не вводит новое толкование законодательства. Нерешённые вопросы прежних многолетних FR0512 и приходского учёта описаны в источниках и исходных материалах.

Индексация пока отключена. `noindex` не делает публичный сайт приватным.

## Изображения и видео

Схема помещения и концепция кухни находятся локально. Исходная концепция кухни имеет разрешение 480 × 270; для дальнейшего улучшения нужен качественный оригинал. Изображение беседки может загружаться с внешнего GitHub-адреса, с подписанной резервной SVG-иллюстрацией при ошибке.

`npm run assets` — необязательное сохранение отсутствующего изображения беседки при наличии сети. После этого нужна новая сборка. Не подменяйте реальные фотографии выдуманными изображениями выполненных работ.

Реальное воспроизведение YouTube, внешние изображения и поведение на физических мобильных устройствах необходимо проверить после включения публичного сайта. Автоматические тесты не заменяют эту проверку. Локальные скриншоты предварительного просмотра не требуются для работы сайта и в репозиторий не переносились.

Дополнительные браузерные тесты требуют Python, Playwright и BeautifulSoup:

```sh
python tests/browser_smoke.py
python tests/browser_http.py
```

Существующие репозитории прихода, кухни и беседки этой загрузкой не изменялись.
