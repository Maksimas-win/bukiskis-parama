НЕЙТРАЛЬНЫЙ ИНФОРМАЦИОННЫЙ САЙТ

Откройте docs/index.html для первого просмотра.
Для полноценной локальной проверки: npm run preview

В этой версии нет крестов, церковного логотипа, фотографии или силуэта храма.
Главное — информация о GPM. Помощь храму вынесена в отдельный раздел.

Загрузите СОДЕРЖИМОЕ папки проекта в отдельный репозиторий GitHub.
Settings → Pages → Deploy from a branch → main → /docs.
Не загружайте ZIP вместо распакованных файлов.

При замене версии 0.1.0 сначала удалите старую папку docs в репозитории,
затем добавьте новую: иначе GitHub может сохранить прежние изображения.
Сборка из исходников также очищает docs автоматически.

Новый репозиторий и публикация ещё не создавались в рамках этой сборки.
Подробности: README.md; проверка: qa/REPORT.md.
