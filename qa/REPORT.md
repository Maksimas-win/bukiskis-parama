# Проверка версии 0.2.0

Дата сборки: 29 сентября 2026 года. Проверялись изменение дизайна, структура сайта и интерфейсные функции. Налоговые правила в рамках этого выпуска повторно не исследовались; источники и периоды сохранены из версии 0.1.0.

## Пройденные проверки

- Сборка шести языковых главных страниц, шести страниц конфиденциальности и корневой русской страницы.
- 14 тестов Node.js: арифметика, проверка ввода, реквизиты и контрольная сумма IBAN, границы кампании, языковые страницы, уникальность ID, ссылки и CSS-ресурсы, отсутствие прежних изображений храма и информационная последовательность разделов.
- Изолированная отрисовка Chromium: шесть языков × четыре ширины (1440, 768, 390, 320 px), 24 сочетания. Нет горизонтального переполнения или необработанных ошибок JavaScript в проверенных состояниях.
- Раскрывающиеся пояснения первого экрана работают нажатием и клавишей Enter, без переполнения на проверенных ширинах.
- Интерактивные проверки: расчёты и ошибочный ввод; шаги инструкции мышью и клавиатурой; создание YouTube iframe только после действия посетителя и его удаление; изображение кухни, поясняющие точки, Escape и возврат фокуса.
- Сценарий без JavaScript: текст инструкции и банковские реквизиты доступны; неработающие элементы копирования не показываются.
- Шесть страниц конфиденциальности проверены на 390 px. Длинные заголовки получили дополнительный перенос для узких экранов.
- Старые SVG храма удалены из исходников и готовой папки. Логотип и favicon используют знак процента. На первом экране нет изображений храма, ссылки на пожертвование или кода конкретного получателя.
- Изображения проекта и документы визуально просмотрены на локальных снимках версии 0.2.0.

## Как проверялось

`tests/browser_smoke.py` использует изолированную HTML-копию с тем же DOM, CSS и JavaScript. Локальные изображения встроены в тестовую копию; недоступное внешнее изображение беседки заменяется штатной подписанной иллюстрацией. CSP убирается только из тестовой копии для её загрузки в среде проверки. В `docs` CSP сохранён. Буфер обмена в этом тесте использует тестовый заменитель браузерного API.

Попытка открыть неизменённые файлы через локальный HTTP-сервер была заблокирована средой Chromium: `net::ERR_BLOCKED_BY_ADMINISTRATOR` на первой навигации. Поэтому реальная HTTP-навигация, выполнение CSP и фактическое разрешение Clipboard API **не подтверждены** этой проверкой. Дополнительный `tests/browser_http.py` оставлен для запуска в среде, разрешающей localhost; его полный сценарий здесь не выполнен.

Скриншоты `preview/*.png` сняты с изолированной тестовой страницы и показывают фактическую отрисовку текущих исходников, а не опубликованный сайт. Скриншоты версии 0.1.0 в архив не включены.

## Не подтверждено этим выпуском

Публикация нового сайта на GitHub; воспроизведение YouTube; загрузка внешнего изображения; поведение на физических устройствах и в Safari/Firefox; административная готовность прихода в VMI; назначение счёта в Mano VMI. Эти сведения не заявляются как проверенные. Проверка контрольной суммы IBAN не устанавливает владельца счёта.

## Воспроизведение проверок

```sh
npm run build
npm test
python tests/browser_smoke.py
python tests/capture_previews.py
```

Python-сценариям нужны Playwright и BeautifulSoup; это дополнительные средства разработки, не зависимости сайта. Итоги проверки адаптивности находятся в `qa/browser-results.json`.
