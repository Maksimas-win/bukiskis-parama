OHNE UNNÖTIGE HÜRDEN

Antworten auf wichtige Fragen.

Ist das eine zusätzliche Zahlung?

Nein. FR0512 weist einen Teil der Einkommensteuer zu; es wird keine zusätzliche Spende vom Bankkonto abgebucht. Eine direkte Überweisung im Spendenbereich ist eine andere Form der Unterstützung.

Wer kann das GPM-Verfahren nutzen?

Das Verfahren betrifft die litauische Einkommensteuer und die VMI-Voraussetzungen. Sprache der Website, Staatsangehörigkeit oder Wohnsitz im Ausland allein bestimmen die Berechtigung nicht. Klären Sie Ihre Steuersituation mit VMI.

Kann ich mehrere Empfänger unterstützen?

Ja. Der Gesamtanteil für Empfänger dieser Kategorie darf 1,2 % nicht überschreiten. Wie Sie diesen Anteil verteilen, entscheiden Sie selbst.

Ich habe früher mehrere Jahre gewählt. Muss ich neu beantragen?

Prüfen Sie bestehende Zuweisungen in EDS. Die Ausführung älterer Anträge nach Wiederherstellung der Berechtigung religiöser Gemeinschaften ab 2027 wird noch geklärt. Eine automatische Wiederaufnahme versprechen wir nicht.

Muss ich GPM311 abgeben?

Wenn Sie zur Einkommenserklärung verpflichtet sind, geben Sie diese innerhalb der VMI-Frist ab. FR0512 ersetzt sie nicht. Werden Erklärungspflichten nicht erfüllt, kann dies die Überweisung der Unterstützung verhindern.

Erhält die Gemeinde über diese Website meine Steuerdaten?

Nein. Hier gibt es kein Formular zur Übermittlung von Steuerdaten. Anträge werden nur in EDS gestellt. Rechnerwerte bleiben in Ihrem Browser.

Wie kann ich ohne GPM helfen?

Sie können freiwillig auf das im Abschnitt zur Gemeindeunterstützung genannte Konto überweisen. Für Sachspenden oder praktische Hilfe wenden Sie sich an die Gemeinde.
